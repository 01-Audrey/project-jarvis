# Project Jarvis

Self-hosted AI assistant inspired by J.A.R.V.I.S. Runs 24/7 on a MacBook with OpenClaw to manage email, reminders, and messages. Every step documented.

> Status: 🚧 In progress. 

## Goals
- [ ] Install OpenClaw and chat with it locally
- [ ] Connect a messaging channel 
- [ ] Set reminders
- [ ] Send texts on my behalf
- [ ] Read and summarize email (read-only first)
- [ ] Run 24/7 in the background

## Stack
- **Hardware:** MacBook Pro (chip / macOS version: TBD)
- **Agent framework:** OpenClaw
- **AI model:** Gemini API (free tier) — can be swapped later
- **Messaging:** Discord
